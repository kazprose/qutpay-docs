# Telegram-бот (@QutPayBot)

Бір платформалық бот — барлық ұйымға ортақ. Кабинетсіз-ақ счёт шығарып, төлем хабарламаларын алуға болады.

## Мерчантқа
1. Кабинет → **Баптау** → **Telegram-бот** → «Байланыстыру кодын алу» (15 минут жарамды, бір рет).
2. Ботқа жеке чатта немесе бот қосылған **топта** `/start КОД` деп жазыңыз (немесе сілтемені ашып «Start»).
3. Осы чатқа келеді: ✅ төлем, ↩️ қайтару, ⌛ мерзімі өткен счёттар, ⚠️ Kaspi сессиясы үзілгені (қайта кіру сілтемесімен).

Командалар:
| Команда | Не істейді |
|---|---|
| `/invoice 5000` | QR/сілтемемен счёт; жауапта төлем беті, «Күйі», «Болдырмау» батырмалары |
| `/invoice 5000 77001234567 Консультация` | Клиенттің Kaspi қосымшасына счёт (телефонға), сипаттамамен |
| `/today` | Бүгінгі түсім, ашық счёттар |
| `/last` | Соңғы 10 счёт |
| `/status inv_…` / `/cancel inv_…` | Счёт күйі / болдырмау |
| `/support мәтін` | Қолдау қызметіне сұрақ жіберу; жауап осы чатқа келеді |
| `/unlink` | Чатты ұйымнан ажырату |

Жеке чатта жай `5000 Сабақ` деп жазса да счёт жасалады. Алиастар: `/счет`, `/шот`, `/бүгін`.
Топтағы **кез келген мүше** счёт жасай алады — топқа кімді қосатыныңызды өзіңіз шешесіз. Қайтару боттан жасалмайды (тек кабинет/API).

## WhatsApp арқылы бір басу
Кіру бетінде «WhatsApp арқылы кіру» → `wa.me/<бизнес-нөмір>?text=Кіру: QP-<id>` ашылады → клиент дайын хабарды жібереді → Meta webhook (`messages`) біздің серверге келеді → жіберушінің нөмірімен кіру расталады, клиентке 24 сағаттық терезеде мәтінмен растау кетеді. Шаблон, тест тізімі, бизнес-верификация керек емес. Meta → Configuration → Webhook fields → **messages** жазылымы қосулы болуы керек.

## Telegram арқылы кабинетке кіру
**Бір басу:** кіру бетінде «Telegram арқылы кіру» → бот ашылады → Start → «📱 Нөмірімді жіберу» → бет өзі кіреді (`/auth/telegram/start` → `t.me/бот?start=auth_<id>` → контакт → `/auth/complete`). Нөмірі бұрын байланысқан адамға контакт сұралмайды. Балама: нөмір + «Telegram» арнасы → код ботқа келеді.

## Платформа әкімшісіне
1. @BotFather → `/newbot` → токен. Кабинет → **Платформа** → «Платформа Telegram бот токені» → Сақтау (DB-де шифрланып сақталады; `.env`-тегі `TELEGRAM_BOT_TOKEN` де жарайды).
2. «Telegram webhook орнату» — `API_URL/telegram/webhook` тіркеледі (құпия заголовок `X-Telegram-Bot-Api-Secret-Token`, TOKEN_SECRET_KEY-ден шығарылады). Сервер қайта қосылғанда автоматты қайталанады.
3. @BotFather → `/setprivacy` → **Disable** — топта `/invoice` командаларын ботқа жеткізу үшін (немесе ботты топ әкімшісі етіңіз).
4. https болмаса (dev) бот long polling режимінде жұмыс істейді (`TELEGRAM_POLLING=1`).
5. **Ескертулер өзіңізге келуі үшін** Платформа бетінде «Telegram-ды байланыстыру» → «Ботты ашу» (немесе ботқа `/start adm_…` кодын жіберу, 15 мин жарамды). Жаңа тіркелу, жаңа ұйым, қолдау сұраулары, токен/лимит ескертулері тек байланысқан әкімшілерге барады; байланыспаған әкімші бетте қызылмен көрінеді. Бұл байланыс кіру нөмірінен бөлек (`tg_admin:<phone>`), сондықтан Telegram аккаунтыңыздың нөмірі кабинет нөмірінен басқа болса да жарайды.

## Ішкі құрылым
- `apps/api/src/services/telegram.js` — Bot API клиенті, команда өңдеу, `broadcast()`.
- `apps/api/src/routes/telegram.js` — webhook. `panel.js` — `/panel/orgs/:id/telegram*`, `/panel/platform/telegram/set-webhook`.
- Кестелер: `telegram_chats` (chat → ұйым), `telegram_link_codes`. Кіру байланысы: `platform_settings.tg_link:<phone>`; әкімші ескертулері: `tg_admin:<phone>` (код арқылы), болмаса `tg_link:<phone>`.
- Хабарламалар `notify.js` ішінде ұйымның өз боты (settings) мен платформа ботының чаттарына қатар жіберіледі; әр жіберу `notifications` кестесіне жазылады.
