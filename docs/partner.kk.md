# Реферал және Partner API

## Реферал (әр мерчантқа)
- Кабинет → **Серіктестік** → жеке код және сілтеме `https://qut.kz/app/login?ref=КОД`.
- Сол сілтемемен тіркелген мерчанттың бірінші ұйымы сізге «жабысады» (`referred_by`).
- Ол тариф төлеген сайын сомадан **20 %** (`REFERRAL_PERCENT`) сізге есептеледі (`referral_earnings`, күйі `accrued`).
- Төлемді платформа қолмен жасайды: Платформа → Сыйақылар → «Төленді» (`paid_out`).

## Partner API (интеграторлар, веб-студиялар, франшизалар)
Шарт: ұйым **«Серіктес»** тарифінде (платформа қояды) және API кілтінде `partner:manage` scope бар.

Серіктес тарифі — **79 900 ₸/ай**, айына 30 000 счёт (клиент ұйымдардың счёттары бұған кірмейді — олар өз кассирлерінен өтеді). Тарифті платформа қосады (бізге жазыңыз), сосын серіктес оны кабинеттің **Серіктестік** бетінен Kaspi арқылы өзі төлейді. Сол бетте **«Клиент ұйымын ашу»** формасы мен клиенттер тізімі бар: API жазбай-ақ ұйым ашуға, иесінің нөмірін беруге және клиенттің API кілтін (бір рет көрсетіледі) алуға болады; тізім `GET /api/v1/partner/organizations` жауабымен бірдей.

| Әдіс | Не істейді |
|---|---|
| `POST /api/v1/partner/organizations` `{name, ownerPhone, ownerName?, legalName?, idn?}` | Клиентке ұйым ашады: иесінің аккаунты (болмаса жасалады), sandbox + 7 күн сынақ, серіктес иесі `developer` мүше, жауапта `apiKey` (бір рет) |
| `GET /api/v1/partner/organizations` | Клиенттер тізімі: режим, тариф, төлем статистикасы, белсенді Kaspi байланыстары |
| `GET /api/v1/partner/organizations/{id}` | Ұйым + байланыстар |
| `POST …/{id}/connections` → `…/{cid}/kaspi/init` → `send-phone {processId, phone}` → `verify-otp {processId, otp}` | Клиенттің Kaspi кассирін қосу (SMS коды кассирдің телефонына келеді) |
| `POST …/{id}/mode {mode: 'live'}` | Live режимге өткізу (белсенді байланыс керек) |
| `POST …/{id}/api-keys {name, scopes?}` | Клиентке жаңа кілт |
| `GET …/{id}/members`, `POST …/{id}/members {phone|email, role: manager|developer, name?}`, `DELETE …/{id}/members/{accountId}` | Клиенттің қызметкерлері: тізім, қосу, алып тастау. Иесін тек клиент өзі өзгертеді; ұйымда ең көбі 10 қызметкер |
| `DELETE /api/v1/partner/organizations/{id}` | Қателесіп ашылған клиентті жабу (архивтеу) — тек ешқашан қолданылмаған ұйым: счёт жоқ, иесі кірмеген. Әйтпесе `409 client_in_use` — жабуды клиенттің иесі кабинетте (Баптау → «Ұйымды жабу») шешеді. Жабу = архивтеу: счёттар мен журнал сақталады, кілттер мен кассирлер тоқтайды |
| `GET /api/v1/partner/earnings` | Реферал коды, клиенттер, есептелген сыйақы |

Клиенттің өз счёттарын серіктес **клиенттің кілтімен** басқарады (`/api/v1/invoices`), немесе кабинетке кіріп көреді.

**Серіктес рөлі.** Серіктес ұйымының иесі мен әзірлеушілері әр клиент ұйымына автоматты түрде «серіктес» рөлімен кіреді (ұйым ауыстырғышта клиенттер тізімде тұрады). Бұл рөл developer-ден жоғары: кілт, webhook, счёт жасайды, тарифті төлей алады, клиентке менеджер/әзірлеуші қоса алады және алып тастайды — бірақ иесін өзгерте, алып тастай алмайды және ұйымды жаба алмайды. Серіктес қызметкері серіктес ұйымынан шықса, барлық клиентке қолжетімділігі бірден тоқтайды; менеджер рөліндегі қызметкерлер клиенттерге кірмейді. Клиенттің иесі кабинетте (Баптау → «Серіктестің қолжетімділігі») серіктестің қолжетімділігін кез келген сәтте тоқтата алады — реферал байланысы сақталады, серіктес қосқан қызметкерлер қалады. Кабинеттің Серіктестік бетінде әр клиенттің «Қызметкерлер» бөлімі бар.

Толық сипаттама: https://api.qut.kz/docs (Partner тегі).
