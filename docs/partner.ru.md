# Рефералы и Partner API

## Реферальная программа (для каждого мерчанта)
- Кабинет → **Партнёрство** → личный код и ссылка `https://qut.kz/app/login?ref=КОД`.
- Первая организация мерчанта, зарегистрировавшегося по этой ссылке, закрепляется за вами (`referred_by`).
- Каждый раз, когда он оплачивает тариф, вам начисляется **20 %** от суммы (`REFERRAL_PERCENT`) (`referral_earnings`, статус `accrued`).
- Выплату платформа делает вручную: Платформа → Вознаграждения → «Выплачено» (`paid_out`).

## Partner API (интеграторы, веб-студии, франшизы)
Условие: организация на тарифе **«Партнёр»** (устанавливает платформа) и у API-ключа есть scope `partner:manage`.

Тариф «Партнёр» — **79 900 ₸/мес**, до 30 000 счетов в месяц (счета организаций клиентов сюда не входят — они идут через их кассиров). Тариф включает платформа (напишите нам), дальше партнёр оплачивает его сам со страницы **«Партнёрство»** в кабинете через Kaspi. На той же странице есть форма **«Открыть организацию клиента»** и список клиентов: организацию можно открыть без кода, указав номер владельца, и получить API-ключ клиента (показывается один раз); список совпадает с ответом `GET /api/v1/partner/organizations`.

| Метод | Что делает |
|---|---|
| `POST /api/v1/partner/organizations` `{name, ownerPhone, ownerName?, legalName?, idn?}` | Открывает клиенту организацию: аккаунт владельца (создаётся, если его нет), sandbox + 7 дней пробного периода, владелец партнёра становится участником с ролью `developer`, в ответе `apiKey` (показывается один раз) |
| `GET /api/v1/partner/organizations` | Список клиентов: режим, тариф, статистика платежей, активные подключения Kaspi |
| `GET /api/v1/partner/organizations/{id}` | Организация + подключения |
| `POST …/{id}/connections` → `…/{cid}/kaspi/init` → `send-phone {processId, phone}` → `verify-otp {processId, otp}` | Подключение кассира Kaspi клиента (SMS-код приходит на телефон кассира) |
| `POST …/{id}/mode {mode: 'live'}` | Перевод в live-режим (нужно активное подключение) |
| `POST …/{id}/api-keys {name, scopes?}` | Новый ключ для клиента |
| `GET /api/v1/partner/earnings` | Реферальный код, клиенты, начисленное вознаграждение |

Счетами клиента партнёр управляет **ключом клиента** (`/api/v1/invoices`) или просматривает их, войдя в кабинет (роль developer).

Полное описание: https://api.qut.kz/docs (тег Partner).
