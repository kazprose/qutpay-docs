# CRM және басқа жүйелерге қосу

Qut Pay-де екі деңгей бар. Біріншісінде — орнатып қоя салатын дайын шешім. Екіншісінде — CRM-іңіздің өз webhook немесе API мүмкіндігі арқылы қосу. Екеуі де жұмыс істейді, айырмашылығы тек қосуға кететін уақытта.

## 1-деңгей. Дайын шешім

Код жазудың қажеті жоқ. Орнатасыз, кілтті қоясыз, жұмыс істейді.

| Жүйе | Не істеу керек |
|---|---|
| WordPress / WooCommerce | [Плагин](https://api.qut.kz/downloads/qutpay-for-woocommerce.zip) → [нұсқаулық](https://api.qut.kz/docs/guide/wordpress) |
| OpenCart 4 | [Модуль](https://api.qut.kz/downloads/qutpay.ocmod.zip), README архивтің ішінде |
| Tilda, Webflow, кез келген HTML форма | Кабинет → Интеграциялар → «Форма-хук», сілтемені форманың action өрісіне қою |
| n8n | [Дайын екі workflow](https://api.qut.kz/downloads/qutpay-n8n.zip): счёт жасау және оқиға қабылдау |
| 1C | [Нұсқаулық](https://api.qut.kz/docs/guide/1c) |
| Telegram | Платформа боты: `/invoice 5000`, төлем хабарламалары ([нұсқаулық](https://api.qut.kz/docs/guide/telegram_bot)) |

## 2-деңгей. API арқылы қосылады

Дайын модулі жоқ, бірақ қосуға болады. Шарт біреу: **CRM сыртқа HTTP сұраныс жібере алуы керек** (көбіне «шығыс webhook», «исходящий вебхук» деп аталады) немесе әзірлеушіңіз болуы керек.

| CRM | Қалай қосылады |
|---|---|
| Bitrix24 | Шығыс webhook немесе n8n |
| amoCRM, Kommo | Digital pipeline webhook немесе REST API |
| Altegio | Webhook және API |
| МойСклад, RetailCRM | REST API |
| Басқа кез келген жүйе | REST API + webhook |

Бұл тізім — мысал, шектеу емес. HTTP сұраныс жібере алатын кез келген жүйе қосылады.

### Ағын

Екі бағыт бар, әдетте екеуі де керек.

**CRM → Qut Pay (счёт жасау).** Мәміле «Төлем күтілуде» сатысына өткенде CRM біздің API-ге сұраныс жібереді, жауапта төлем сілтемесі мен QR келеді.

```
POST https://api.qut.kz/api/v1/invoices
X-API-Key: qp_live_…
Content-Type: application/json

{
  "amount": 25000,
  "description": "Мәміле #1042",
  "externalOrderId": "1042",
  "metadata": { "dealId": "1042", "manager": "Айгүл" },
  "customer": { "phone": "77001234567", "name": "Клиент" }
}
```

Жауапта `payUrl`, `qrUrl` және `id` келеді. Сол сілтемені CRM клиентке жібереді.

Егер CRM JSON жібере алмай, тек қарапайым форма жібере алса — «Форма-хук» пайдаланыңыз, ол `amount`, `phone`, `email`, `name`, `comment` өрістерін өзі таниды.

**Qut Pay → CRM (төлем туралы хабар).** Клиент төлегенде біз сіздің адресіңізге webhook жібереміз. Ішінде `metadata` мен `externalOrderId` сол күйінде қайтады, сондықтан қай мәміле төленгені бірден белгілі.

```json
{
  "event": "invoice.paid",
  "invoice": {
    "id": "inv_…",
    "status": "paid",
    "amount": 25000,
    "externalOrderId": "1042",
    "metadata": { "dealId": "1042", "manager": "Айгүл" },
    "paidAt": "2026-09-10T05:12:00.000Z"
  }
}
```

Қолтаңба `X-QutPay-Signature` тақырыбында, HMAC-SHA256. Тексеру мысалдары: [Сайтқа интеграция](https://api.qut.kz/docs/guide/integration).

### Әзірлеушіңіз болмаса

[ЖИ-агентке арналған нұсқаулықты](https://api.qut.kz/docs/guide/for_ai) толығымен көшіріп, ChatGPT-ге, Claude-қа немесе Cursor-ға беріңіз де, «менің CRM-іме Qut Pay төлемін қос» деп тапсырма беріңіз. Нұсқаулықта барлық endpoint, өріс және qateler тізімі бар. API кілті мен webhook құпиясын чатқа жазбаңыз, оларды тек өз серверіңізге қойыңыз.

Кабинетте де сол мәтін дайын тұр: Интеграциялар → «ЖИ-агентке нұсқаулық» → «Тапсырмамен бірге көшіру».

### Тексеру

Алдымен sandbox режимінде жасаңыз, ол нақты ақшасыз жүреді. Счёттың күйін кабинеттен қолмен өзгертіп, CRM-іңіз webhook-ты дұрыс өңдейтінін тексересіз. Бәрі дұрыс болса, кабинет → Kaspi → кассирді қосып, live режимге ауысасыз.
